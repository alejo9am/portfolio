## Sobre el Proyecto

Este sitio web es una aplicación estática de alto rendimiento construida con **Astro**. El objetivo principal es ofrecer una experiencia de usuario fluida (sin tiempos de carga) y una excelente puntuación en SEO, manteniendo un diseño minimalista y profesional.

### Características Principales
- **Rendimiento Extremo:** Carga instantánea gracias a la arquitectura "Island Architecture" de Astro.
- **Responsive Design:** Adaptado perfectamente a móviles, tablets y escritorio.
- **Accesibilidad:** Estructura semántica y optimizada.
- **Modo Oscuro/Claro:** Soporte nativo para preferencias del sistema.

## Instalación y Ejecución Local

Si deseas ejecutar este proyecto en tu entorno local para ver cómo funciona o realizar modificaciones:

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/alejo9am/portfolio.git
   cd portfolio
   ```

2. Instalar dependencias

   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo

   ```bash
   npm run dev
   ```

   Abre tu navegador en http://localhost:4321 para ver la aplicación.

4. Construcción para producción (opcional)

   ```bash
   npm run build
   ```

## Despliegue
El proyecto está configurado para desplegarse automáticamente a través de Vercel. Cada vez que se realiza un push a la rama main, Vercel construye y publica la nueva versión en segundos.
